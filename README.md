ocaml-lsp for oxcaml
=================================
This is version of `ocaml-lsp` developed by JaneStreet and tailored towards working with `oxcaml`.

Contributing
============

A lifecycle of an OSS contribution to this repo is:
1. a PR is made on github
2. a review happens until the PR is approved
3. the PR is not merged, but rather imported by a JaneStreet employee into JaneSteet's internal repository
4. internal validation happens
5. a sync from the internal repository to this repository brings the change into the main branch

Build
-----
To build the repo:
```
$ make buildoss
```
